# Post-v0.1.0 Roadmap

**Task ID:** T-2026-06-28-001
**Status:** in_progress
**Owner:** master
**Phase:** post-release evolution

## Goal

Move agents-manager from v0.1.0 (initial public release) to v0.3.0 (production-grade with CI, full Tier 3 skill coverage, and example downstream projects).

## Plan summary

Four-phase rollout:

| Phase | Title | Output | Effort |
|---|---|---|---|
| 1 | GitHub Actions CI | `.github/workflows/ci.yml` + `scripts/validate-frontmatter.py` + `.gitattributes` | 1–2h |
| 2 | v0.2.0 Tier 3 skill integrations | Master prompt + coder rules + Phase 5 (optional branch close) | 30–60m |
| 3 | Examples directory × 3 | `examples/{node-markdown-linter,python-csv-summarizer,docs-restructure}/` + index README + replay scripts | 3–6h |
| 4 | obra/superpowers sync (recurring) | Quarterly `npx skills check` + override updates + CHANGELOG entries | 30m/quarter |

**Recommended order:** 1 → 2 → 3 → 4 (recurring).

## Phase 3 — Examples directory × 3

### Goal
Provide three self-contained examples demonstrating agents-manager on real tasks. Each example is replayable.

### Selected examples
1. **node-markdown-linter** — Add rule flagging consecutive H1 headings
2. **python-csv-summarizer** — Add `mean` aggregation
3. **docs-restructure** — Move API reference under `docs/api/` and update internal links

### Per-example structure
```
examples/<name>/
├── README.md            ← what user asked, what came out
├── original/            ← starting state
├── installed/           ← after ./bin/install.sh
├── user-task.md         ← exact user request
├── share/               ← populated artifacts
├── tasks/               ← task tracker state
├── expected-output/     ← diff showing end-state
└── replay.sh            ← repeatable demo
```

### Files

### Verification

## Phase 4 — obra/superpowers sync (recurring)

### Goal
Stay current with upstream skill evolution without breaking our overrides.

### Cadence
Quarterly (Jan, Apr, Jul, Oct). Trigger: GitHub Action `schedule: cron: '0 0 1 */3 *'` posts reminder issue.

### Procedure
1. Run `npx --yes skills check --skill <each-skill-name>`
2. Read upstream diffs for each updated skill
3. Update `agents_manager/SKILL.md` overrides section if conflicts
4. Add `## obra sync YYYY-MM-DD` entry to `agents_manager/CHANGELOG.md`

### Files
- **NEW:** `docs/MAINTENANCE.md` — quarterly procedure
- **NEW:** `.github/workflows/obra-sync-reminder.yml`

### Status: pending (recurring)
