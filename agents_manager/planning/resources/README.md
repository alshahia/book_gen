# Planning Resources

This folder holds planning templates, project conventions, and reusable patterns.

Read on demand. Deep-read only what's relevant to the current task.

## Suggested starter entries (to be added)

- `task-format.md` — pinned canonical task table schema (mirror of `SKILL.md` § 3)
- `phase-patterns.md` — common phase shapes: feature-add, refactor, bug-fix, migration
- `naming-conventions.md` — file/class/function naming used in this repo
- `testing-conventions.md` — test framework, naming, locations
- `commit-conventions.md` — if the project uses conventional commits or similar

## Reuse over reinvention

Before writing a new plan from scratch:
1. List `notes/` and skim the last 5 plans.
2. Look for a plan that solved a similar shape (feature-add, refactor, bug-fix).
3. Copy the skeleton, adapt the contents.

Plans are **append-only** once written. Don't delete old plans; supersede them.
