# Research Resources

Place curated references, links to relevant docs, and prior-decision excerpts here.

This folder is **read on demand** — you are not required to load every file every time. Skim its contents once at the start of a task; deep-read only what's relevant.

## Suggested starter entries (to be added as the project grows)

- `tech-stack.md` — pinned versions, why each was chosen (mirror of `AGENT_temp.md` § Tech Stack)
- `glossary.md` — domain terms used in this repo
- `prior-decisions.md` — links to entries in `research_doc/decisions/`
- `known-pitfalls.md` — issues we've hit before in this repo
- `external-docs.md` — hand-picked doc URLs with one-line summaries

## Reuse over reinvention

Before researching an API or pattern, **always check**:
1. `notes/` in this folder — your past self may have written it
2. `../../research_doc/` — the project-wide research doc index
3. `../../AGENT_temp.md` — the standing project rules

If a topic is already covered, link to it and stop. Do not re-research.
