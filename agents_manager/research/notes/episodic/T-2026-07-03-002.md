## TL;DR
The v0.13.0 memory frontmatter requires six keys; `superseded_by` is required only when `status: superseded`.
## Context
T-2026-07-03-002: pre-locked validation of the three-scope memory design. Schema mismatch would silently break `scripts/validate-memory.sh`.
## Insight
Default `active` does NOT require `superseded_by`. The validator fails entries with `superseded_by` without `status: superseded` AND entries with `status: superseded` lacking a resolvable `superseded_by` path.
