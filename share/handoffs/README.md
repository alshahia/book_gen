# User Task Capture

This is the **first file** the master writes, at Phase 0. It freezes the user's request in time so that downstream agents never have to guess.

## Template

```markdown
# User Task — <task-id>

**Captured:** YYYY-MM-DD HH:MM
**Source:** <direct user message | pasted | summarized>

## Verbatim request
>
> <the user's words, line by line, in a blockquote. Do not edit.>

## Master one-line restatement
<one sentence — show the user you understood>

## Task id
`T-YYYY-MM-DD-NNN`

## Status
- [ ] Phase 0 — Ingest (this file)
- [ ] Phase 1 — Research
- [ ] Phase 2 — Planning
- [ ] Phase 3 — Build
- [ ] Phase 4 — Review
- [ ] Completion
```
