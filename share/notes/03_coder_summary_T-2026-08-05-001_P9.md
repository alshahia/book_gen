## Implementation notes

### `duckduckgo_search.py` (NEW - 147 lines)

- UTF-8 stdio force at module top, BEFORE any argparse / print call (WARN #15 + #22 inheritance). Pattern is the gate_summary.py shape (module-level `_force_utf8_stdio()`-equivalent block, not the older inside-main() pattern).
- ASCII-only docstring (no `>=`, `->`, em-dash, U+2502 box-drawing).
- Single import-safe function `duckduckgo_search(query: str, max_results: int = 10) -> list[dict]`. The function makes no network side effect at import time.
- `urllib.request` against `https://html.duckduckgo.com/html/?q=<query>` with a real-browser User-Agent (avoids the DDG captcha path for light queries).
- Parses `result__a` (href + inner title text) and `result__snippet` classes via two stdlib regexes. Resolves DDG redirect URLs (`//duckduckgo.com/l/?uddg=...`) to the real destination.
- Returns `[]` (with a stderr line) on any network failure so the parent pipeline never crashes on a flaky DDG response.

### `parallel_search.py` (NEW - 281 lines)

- UTF-8 stdio force at module top, BEFORE any argparse / print call.
- ASCII-only docstring.
- Two-layer architecture:
  1. CLI `main(argv)` - reads `--exa-results <path>` / `--firecrawl-results <path>` JSON files, tags with `source:`, dedups, optionally invokes DDG subprocess when `--fallback` and `len(unique) < 3`, appends one `layer=...` line per layer to `share/notes/01_research_<task>_search-trail.md`.
  2. Pure function `parallel_search(query, max_results, fallback, *, exa_fn=None, firecrawl_fn=None, ddg_fn=None, trail_path=None)` - the testable surface. Callables default to no-ops so tests inject mocks without touching the network or the MCP layer.
- CLI `_load_layer` is BOM-resilient (`encoding="utf-8-sig"`); PowerShell's `Out-File -Encoding utf8` emits a BOM which would otherwise crash `json.loads`.
- DDG invocation is wrapped in try/except around subprocess + a timeout; failures return `[]` and surface on stderr (parent never crashes).
- Imports `dedup_results` as a top-level name (the conftest pre-pends `book-kit/book_workflow/scripts` to `sys.path`, so this is reliable in both CLI and test contexts).
- The fallback rule is `UNIQUE_THRESHOLD = 3` (verbatim from spec): only fire DDG when the dedup'd primary union has fewer than 3 unique URLs.

### `dedup_results.py` (NEW - 152 lines)

- UTF-8 stdio force at module top, BEFORE any argparse / print call.
- ASCII-only docstring.
- `canonicalize(url)` lowercases scheme + host, strips the 6 `utm_*` keys (preserves all other query params in input order), normalizes trailing slash on non-root paths (root `/` is preserved for forward compatibility - some servers distinguish `/` from no-path).
- `dedup(results)` rewrites each `url` to its canonical form and dedupes by canonical URL keeping the first occurrence. `source` tags survive the round-trip.
- Importable as `from dedup_results import canonicalize, dedup` (verifiable by the test file).
- CLI reads from a file path or stdin (`-`); BOM-resilient via `encoding="utf-8-sig"`.
- Fragments preserved verbatim (spec didn't ask to strip them).
