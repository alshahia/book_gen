## Task in one sentence

Survey + design a `agents_manager` meta-capability that turns a finished project into either (A) a reusable template under `templates/<name>/` (for other projects to clone) or (B) extracted core knowledge (for agents on similar projects to consume). Both sub-asks operate on the *output* of a completed Phase-3 build.

### F7. The dispatch's "~30s" framing is wrong — must reframe

The Operations angle flagged this as a UX lie: producing a minimal-legal template is the 9-step `templates/AUTHORING.md` recipe (cp starter → fill INDEX → memory files monotonic → skeleton last → verify.sh → Rule 8 checklist → PR), which is **hours-to-days for a newcomer, 30-60 minutes for a contributor who knows the rulebook**. The scaffold step is ~30s; the rulebook-driven completion is not.

**Honest prompt:** "Scaffold a starter template (~30s — fills placeholders only; complete the 9-step recipe in `templates/AUTHORING.md` afterwards)."

### F8. Risk surface (merged + dedup, prioritized)

**HIGH:**
- **R1 (A1+R1+C1).** Soft-wall erosion / memory cross-contamination. Avoid via shell-out CLI (no SKILL.md amendment needed).
- **R2 (A2+C5).** IP / license contamination. Pre-flight: detect `LICENSE`, require `templates/<name>/LICENSE` declaration; refuse otherwise.
- **R3 (A3+C3).** Secrets exfiltration. Pre-flight denylist: `.env*`, `*.pem`, `*.key`, `id_rsa*`, `02_secrets_*`, plus `sk-[A-Za-z0-9]{20,}` and `-----BEGIN … PRIVATE KEY-----` regex.
- **R4 (C4+R4).** Capability overlap / authoring-standard drift. Reuse existing mechanisms; emit content that passes `tests/verify.sh`.
- **R5 (C2).** UX framing mismatch. Reframe prompt; don't lie about scope.

**MEDIUM:**
- R6 (C4). Template ships with bugs from source's open WARNs. Refuse if `04_warns_register_<source>.md` has OPEN entries.
- R7 (B3+R8). Cross-pollination across memory scopes. Require user-confirmed scope choice per entry.
- R8 (C8). Duplicate templates (Jaccard >0.6 with existing). Refuse and surface "promote instead".
- R9 (A5+C5). License of source repo may not permit redistribution. Pre-flight detection required.

**LOW:**
- R10 (A6+C9). Template drift / staleness. Use `controller_compat: >=v0.14.1` frontmatter on `00-readme-first.md`; verify.sh refuses to consume if compat floor > running version.
- R11 (C6). Skip button fatigue. Per-project opt-out flag; auto-disable after 3 consecutive skips.
- R12 (A4+C1). Over/under-generalization. Trigger-line frontmatter required (R4); generalize-and-redact pass before emit (R5).

### F9. am-review FAIL conditions (merged from Operations C-F1..F8)

A new template extracted from a project MUST pass all 8 before ship:

1. `tests/verify.sh` exits 0 (no placeholder PASS lines)
2. Every `assets/MANIFEST.txt` line resolves to an existing file
3. Every memory file has `USE THIS WHEN:` on its H1
4. Every memory file's H1 number matches its filename prefix
5. `templates/<name>/LICENSE` exists and is on the rulebook's whitelist (MIT, Apache-2.0, BSD-2/3, ISC, CC0, CC-BY, or user-declared-equivalent)
6. No secrets in `skeleton/` (`.env`, `sk-…`, `-----BEGIN … PRIVATE KEY-----` — all 0 hits)
7. `INDEX.md` has real trigger phrases (≥1 under `## Use when | ## Trigger phrases | ## Use this template when`), not boilerplate
8. Source project's `04_warns_register_<source>.md` has 0 OPEN entries (or user explicitly accepts propagation)

**Verify commands:** see Operations angle F1-F8 verbatim (each has a one-liner shell check).
