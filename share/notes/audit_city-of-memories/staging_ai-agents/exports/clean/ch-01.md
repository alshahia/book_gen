# Chapter 1 — Meet Python and AI Agents

Before you open a terminal, picture explaining an AI agent to a new coder. By the end, you’ll have plain-language definitions for Python, large language models, and agents, plus one safety rule: model output is a draft, not an instruction to trust automatically.



## Start with Python

Python’s official FAQ defines Python as an interpreted, high-level, general-purpose language with readable syntax, built-in libraries, and third-party packages. The official Python tutorial says it skips a compile-and-link step and supports interactive use across operating systems, lowering a beginner’s barrier.

## Understand the language model

IBM defines an LLM as a deep-learning model trained on vast text collections. It predicts the next token—a small unit of text—from prior context.

IBM’s *Evaluating LLMs* section warns that plausible output can be false, a problem called hallucination. It can also reflect training-data bias, while training and running models consume substantial computing resources and energy. Check the draft before it influences an action.

## Let model output steer the program

The Hugging Face smolagents guide gives one compact definition: “AI Agents are programs where LLM outputs control the workflow.” The guide’s spectrum runs from showing model text to choosing tools, repeating steps, or starting another agent.

Anthropic’s *Building effective agents* distinguishes a workflow, whose route is predefined in code, from an agent, whose model chooses the next step and tool. Anthropic describes production agents as bounded by human goals, review checkpoints, and maximum step counts.

## Put tools inside boundaries

The smolagents package guide defines a tool as a typed Python function with a clear docstring. The model uses that description to choose the function. Its `CodeAgent` can execute model-generated Python, so the guide recommends isolated execution when prompts or retrieved content aren’t fully trusted.
