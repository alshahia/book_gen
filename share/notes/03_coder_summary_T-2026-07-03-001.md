## Recovery: opencode.jsonc corruption

The first attempt to insert the `am-assets` entry via the `edit` tool failed because:
1. The `read` tool's display truncation marker `(line truncated to 2000 chars)` was inside the prompt string at character 2000.
2. My `edit` tool's `newString` parameter inadvertently contained this literal text from the display output instead of the actual prompt content.
3. The `edit` tool also converted the JSON `\n` escape sequences into real newlines, which broke the file.

**Recovery steps:**
1. Restored original `opencode.jsonc` from git: `git show HEAD:opencode.jsonc > /tmp/opencode_original.jsonc`
2. Extracted each of the 6 original agent prompts (master 2175, am-research 2260, am-planning 2114, am-design 3656, am-coder 2743, am-review 2545 chars) — each was a JSON-escaped string starting with `"You are..."` and ending with `,` (between `}` and `,`).
3. Read the `am-assets` prompt from `C:\Users\AHMADM~1\AppData\Local\Temp\opencode\rebuild_input_am_assets_prompt.txt` (the extracted text via PowerShell Substring which preserved the actual file content, not the read-tool display).
4. Wrote `rebuild_opencode.py` that:
   - Loads the original `opencode.jsonc` (6 agents)
   - Re-encodes each prompt via `json.dumps` to ensure proper escaping
   - Concatenates the 7 agents into the file template
5. Wrote the new `opencode.jsonc` from the rebuild output.
