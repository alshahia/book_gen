## Implementation notes (for review)

- **HTML-only mode**: `--html-only` is a real flag in the CLI (not a hidden test fixture). It writes the assembled HTML and skips Chrome — exits 0. This is the canonical path for the no-browser environment the dispatch flagged. The acceptance-criteria "PDF inspection" tests inspect the assembled HTML (5 of the 5 acceptance criteria present in the string output), not a real PDF.
- **Chrome-absent split**: when `--book` is requested without `--html-only` and Chrome is missing, exit 3 surfaces the deferral message and tells the user to install Chrome or re-run with `--html-only`. Verified by `test_chrome_absent_exits_three`.
- **Style-guide frontmatter parser**: a deliberately minimal YAML subset (no `pyyaml` dependency added). Handles `key: value`, flow maps (`fonts: {body: X}`), one level of indented nested mappings, and `|/-` block scalars (`cover_text: |`). Real book style guides pass through this; if a future style guide uses a richer YAML shape, the script falls back to defaults for the missing piece.
- **Paper size resolution**: `B5` → `176mm 250mm`. Unknown sizes pass through verbatim as a CSS size (so `210mm 297mm` works too). Pre-defined aliases: A4, A5, A6, B5, B6, Letter, US-Letter, Legal, Crown-Quarto, Royal.
- **Page numbers**: `@page { @bottom-right { content: counter(page); } }` plus `@page :first { @bottom-right { content: "" } }` so the cover stays clean. Bundled into the assembled HTML's `<style>` block alongside the existing DEFAULT_CSS.
- **Auto-linked ToC**: each chapter's section gets an `id` derived from the filename slug (`ch-01.md` → `id="ch-01"`). Duplicate slugs get a `-N` suffix. The ToC is `<nav class="book-toc"><ol><li><a href="#ch-01">...</a></li></ol></nav>` between preface and chapters.
- **P11 integration**: `resolve_chapter()` checks `chapters-rendered/` first (the P11 mirror), then `chapters/`, then the bare href. This is the path the orchestrator's Phase 6 paragraph explicitly calls out.
- **Path hardening**: `resolve_under()` is the same shape P11 introduced — refuse `..` components, refuse absolute paths outside the book root. Applied to `--out`, `--toc`, `--style-guide`, and the chapter paths resolved from `toc.md` (defense in depth: a malicious `toc.md` listing `../../../etc/passwd` can't escape the book root either).
- **Subprocess**: `chrome_pdf_command()` returns a list, called with `subprocess.run(..., capture_output=True)` and the default `shell=False`. The PDF path is collected from `--print-to-pdf=<path>` and the URL is the HTML file's `as_uri()`.
